§6 Representação computacional

Objetivo do bloco: guardar um grafo em duas estruturas clássicas, comparar o custo das operações elementares e extrair da matriz de adjacências informação combinatória (graus, caminhos de comprimento 2, triângulos).

6.1 Mapear V em {1,…,n}

Máquinas gostam de índices. Conjuntos abstratos, não. O primeiro passo de qualquer algoritmo em grafos é construir um isomorfismo entre V(G) e {1, 2, …, |V(G)|}. Feito isso, o problema original é resolvido sobre um grafo isomorfo G′ com V(G′) = {1,…,n}, e a estrutura de busca que realizou o mapeamento (tabela de espalhamento ou árvore binária de busca, por exemplo) traduz a resposta de volta aos nomes originais.

Convenção do resto do texto

Daqui em diante, todo grafo tratado computacionalmente tem V = {1, 2, …, n} para algum n ∈ ℕ. Escrevemos n = |V| e m = |E|.

Por que isso não perde generalidade

Isomorfismo preserva tudo o que os algoritmos deste curso perguntam: adjacência, grau, caminhos, ciclos, componentes. Relabelar vértices com 1 a n é só escolher um desenho conveniente do mesmo objeto — o mesmo espírito do capítulo 3, agora com um motivo de engenharia.

6.2 Matriz de adjacências

A ideia é a mais crua possível: uma tabela n × n em que a posição (i,j) diz se {i,j} é aresta.

Definição · matriz de adjacências

A matriz de adjacências de G é a matriz n × n denotada por A(G), ou A, definida por

Aij = 1 se {i,j} ∈ E(G);   0 caso contrário.

Em grafo simples não há laço, logo a diagonal é toda zero. A aresta não tem direção, logo A é simétrica: Aij = Aji.

Atenção · o 1 da posição (i,j) não é um peso

Aqui 1 significa “existe a aresta”, não “a aresta custa 1”. Grafos ponderados usam uma matriz de pesos, com a convenção extra de o que pôr nas posições sem aresta (0, ∞ ou um sentinela — e isso muda de livro para livro). Neste capítulo, A é 0-1.

O original ilustrava um grafo de 6 vértices (o G do exemplo 8). A figura de lá não pôde ser extraída, e para conferir A2 e A3 à mão um exemplo menor é mais útil. Usaremos daqui até o fim do bloco o grafo abaixo — construído para esta versão.

Exemplo · um grafo de 4 vértices, daqui até A³
V = {1, 2, 3, 4}
E = { {1,2}, {1,3}, {2,3}, {2,4} }

Um triângulo sobre {1,2,3} e um vértice pendente 4 ligado a 2. Graus: d(1) = 2, d(2) = 3, d(3) = 2, d(4) = 1. Conferência: soma dos graus 2+3+2+1 = 8 = 2·4 ✔

6.3 Lista de adjacências

Em vez de reservar uma casa para cada par de vértices, guardamos, para cada vértice, só quem realmente é vizinho.

Definição · lista de adjacências

A lista de adjacências de G é um vetor N[1..n] de listas ligadas. A lista N[i] contém os vizinhos do vértice i. Cada nó da lista armazena um vértice e um ponteiro para o próximo nó.

Observação 6 · a lista não é única

Qualquer permutação dos nós de N[i] é uma lista válida. Algoritmos que “percorrem os vizinhos” podem, portanto, visitar a vizinhança em ordens diferentes conforme a implementação — e isso às vezes muda o caminho que BFS/DFS devolve, nunca a existência do caminho.

Espaço: há n cabeças de lista e, no total, 2m nós (cada aresta contribui um nó em cada extremo). Logo Θ(|V| + |E|). Em grafo esparso isso é muito menor que n2.

6.4 Três tarefas, dois custos

A pergunta certa não é “qual representação é melhor”, e sim “melhor para quê”. Três operações elementares bastam para sentir a diferença. Os tempos abaixo são no pior caso, para um grafo G = (V, E) já armazenado.

TarefaMatriz de adjacênciasLista de adjacências
{i,j} ∈ E? O(1) — lê Aij O(|V|) — percorre N[i], que tem no máximo n−1 nós
Determine d(i) O(|V|) — soma a linha i O(|V|) — conta os nós de N[i] (na verdade O(d(i)))
Devolva E O(|V|2) — varre a matriz O(|E|) — percorre as listas (mais precisamente O(|V| + |E|))

Em grafo simples vale

0 ≤ |E| ≤ |V| · (|V| − 1)2.

Por isso “devolva E” é mais barato em lista quando há poucas arestas: você paga proporcional ao que existe, não ao que poderia existir. Já o teste “{i,j} é aresta?” é o argumento clássico a favor da matriz.

Receita: qual estrutura usar
  1. O algoritmo pergunta muitas vezes “ij é aresta?”. Matriz. Cada pergunta sai de graça.
  2. O algoritmo percorre vizinhanças (BFS, DFS, Dijkstra, Kruskal…). Lista. Você só toca quem é vizinho.
  3. O grafo é denso (m da ordem de n2). As duas estruturas ocupam Θ(n2); a matriz costuma ser mais simples.
  4. O grafo é esparso (m = O(n)). Lista, sem discussão — a matriz desperdica quase toda a memória.

6.5 O-grande e a observação 7

Neste texto, complexidade de um algoritmo significa complexidade de tempo no pior caso. A expressão é escrita em função do tamanho da representação e em notação assintótica.

Definição · f(n) = O(g(n))

Sejam f e g funções nos naturais. Dizemos que f(n) = O(g(n)), para n suficientemente grande, quando existem constantes positivas c e n0 tais que, para todo n ≥ n0,

f(n) ≤ c · g(n).

No nosso caso, n é o tamanho da representação do grafo — não necessariamente |V|.

Receita: como provar f = O(g)
  1. Exiba as constantes. Não basta dizer “cresce parecido”. Produza c e n0.
  2. Use desigualdades, não limites. Se f(n)∕g(n) tende a uma constante, qualquer cota maior que o limite serve como c a partir de algum n0.
  3. Lembre a álgebra. O(f) + O(g) = O(max{f,g}). Em particular, se f = O(g) então O(f) + O(g) = O(g) — é o exercício 40.
  4. Uma função, não um grafo isolado. O compara funções de n. Um grafo só não tem “crescimento”. Quando o enunciado diz “para todo G”, leia: a desigualdade vale uniformemente na família de todos os grafos, com as mesmas constantes.

Constantes escondidas mentem em instâncias pequenas. O original compara dois algoritmos para a mesma tarefa: o algoritmo A gasta |V|2 passos; o algoritmo B gasta (|V| + |E|) log |E| passos (logaritmo natural, que é o que faz as contas do original fecharem).

FamíliaQuem ganha
Grafos com m = n2∕4 arestas (densos) A é sempre melhor: n2 contra cerca de (n2∕2) ln n
Grafos com m = 1000n arestas (esparsos) A é melhor para n ≤ 16 644; B passa à frente para n ≥ 16 645

Conferência no limiar esparso, com ln: a desigualdade n2 ? 1001n · ln(1000n) reduz-se a n ? 1001 ln(1000n). Para n = 16 645 temos ln(1,6645·107) ≈ 16,628 e 1001 · 16,628 ≈ 16 645 ✔ (os gráficos do original, figura 9, cobriam entradas até uns 25 mil vértices; a tabela acima substitui os dois desenhos que não puderam ser extraídos.)

Observação 7

Um algoritmo em grafo é de complexidade polinomial se a complexidade de tempo no pior caso é uma função polinomial no tamanho da representação. Complexidade polinomial é independente da representação do grafo por matriz ou por lista de adjacências: as duas representações são polinomialmente relacionadas.

Por que isso é verdade (esboço; a prova completa é o exercício 43). Seja n = |V| e m = |E|. O tamanho da matriz é Θ(n2); o da lista é Θ(n + m). Como 0 ≤ m ≤ n(n−1)∕2, cada tamanho é limitado por um polinômio no outro: n + m = O(n2) e n2 = O((n+m)2). Compor um polinômio com um polinômio continua sendo polinômio. Logo “tempo polinomial no tamanho da matriz” e “tempo polinomial no tamanho da lista” descrevem a mesma classe de algoritmos. □

Atenção · polinomial ≠ prático

A observação 7 fala de classe, não de constante. Um algoritmo O(n100) na matriz continua polinomial na lista, e continua inútil. O que a observação garante é só isto: você não muda de lado da fronteira P / não-P apenas por trocar matriz por lista.

6.6 O que A² e A³ contam

A matriz de adjacências não é só uma tabela de bits. Produto de matrizes conta caminhos.

Lema · entradas de Ak

Seja A a matriz de adjacências de G. Para todo inteiro k ≥ 1, a entrada (Ak)ij é o número de passeios de comprimento k de i a j (sequências de k+1 vértices, não necessariamente distintos, em que cada par consecutivo é aresta).

O caso k = 2 cabe numa frase. Se B = A2 e b(i,j) são as entradas de B:

  • Na diagonal, b(i,i) = d(i). Motivo: um passeio de comprimento 2 que volta a i é “ir a um vizinho e voltar”. Há um por vizinho.
  • Fora da diagonal, b(i,j) = |N(i) ∩ N(j)|: o número de vizinhos comuns — equivalentes aos passeios i — w — j.

Traço

O traço tr(A) é a soma das entradas da diagonal. Em grafo simples, tr(A) = 0. E

tr(A2) = ∑i ∈ V d(i) = 2|E(G)|.

No exemplo: tr(A2) = 2+3+2+1 = 8 = 2·4 ✔

Para k = 3, a diagonal de A3 conta passeios fechados de comprimento 3. Cada triângulo {i,j,k} contribui dois passeios fechados em cada um dos três vértices (ijki e ikji). Logo cada triângulo é contado 3 · 2 = 6 vezes no traço.

número de triângulos de G = tr(A3)6.

No exemplo, o produto A · A2 tem diagonal (2, 2, 2, 0), traço 6, e 6∕6 = 1 triângulo — exatamente o {1,2,3} da Figura 1. O vértice 4 não entra em triângulo nenhum, e de fato (A3)44 = 0 ✔

Receita: triângulos via álgebra linear
  1. Contar. Calcule A3 (ou só a diagonal) e devolva tr(A3)∕6.
  2. Detectar. Basta saber se existe algum. Equivalente: tr(A3) > 0, ou: existe par i < j com Aij = 1 e (A2)ij ≥ 1 (aresta cujos extremos têm vizinho comum).
  3. Complexidade. O produto ingênuo de matrizes n × n custa O(n3). Em 1990, Coppersmith e Winograd mostraram que o produto pode ser feito com O(n2,376) operações aritméticas — e isso já detecta triângulo (exercício 47). O expoente atual é menor; o enunciado usa o número histórico.

6.7 Autovalores, o mínimo necessário

Os exercícios 48 e 50 pedem dois fatos de álgebra linear, não um curso de teoria espectral. Aqui está o que eles exigem, e nada mais.

Como A é real e simétrica, todos os seus autovalores são números reais, e existe base ortonormal de autovetores. Um automorfismo de G é uma permutação de V que preserva arestas; em matriz, é uma matriz de permutação P tal que PA = AP. O conjunto desses automorfismos, com a composição, é o grupo dos automorfismos Aut(G).

Dois fatos que os exercícios usam
  1. Completo. A(Kn) = J − I, onde J é a matriz de uns. Autovalores: n−1 (multiplicidade 1) e −1 (multiplicidade n−1).
  2. Regular. Se G é r-regular, cada linha de A soma r, logo A1 = r1: r é autovalor, com autovetor o vetor de uns.

Além disso: se os n autovalores de A são todos distintos, as matrizes que comutam com A são simultaneamente diagonalizáveis na base de autovetores — e portanto comutam entre si. Em particular Aut(G) é abeliano. A prova escrita é o exercício 48.

Atenção · autovalor distinto não classificou o grafo

“Autovalores distintos ⇒ grupo abeliano” é uma implicação, não uma equivalência. Há grafos com autovalores repetidos e mesmo assim Aut(G) abeliano (por exemplo o caminho P2, cujo grupo é trivial). Não use a recíproca.

6.8 Dígrafos: incidência, subjacente, sorvedouro

Os exercícios 45, 51 e 52 saem do grafo não-dirigido. As três noções abaixo são o vocabulário que eles usam. Em grafo dirigido D = (V, E), cada aresta é um par ordenado (u,v): dizemos que a aresta sai de u e chega em v.

Definição · vetores de incidência S e C

Os vetores S e C são indexados por E. Se e = (u,v), então S[e] = u (saída) e C[e] = v (chegada). Consultar as extremidades de uma aresta dada é O(1); descobrir todas as arestas que saem (ou chegam) de um vértice exige varrer as |E| posições.

Definição · matriz de incidências B

Uma matriz de incidências de D é a matriz B de dimensão |V| × |E| (linhas = vértices, colunas = arestas) dada por

B(i,j) = −1 se a aresta j sai de i; +1 se chega em i; 0 caso contrário.

Cada coluna tem exatamente um −1 e um +1. O produto BBT é |V| × |V| e coincide com o laplaciano do grafo subjacente (possivelmente com arestas múltiplas, se ambos os sentidos existirem): na diagonal, o grau total din(i) + dout(i); fora da diagonal, −(número de arcos entre os dois vértices, em qualquer sentido).

Um exemplo mínimo, para não deixar a fórmula no vácuo. Seja V = {1,2,3} e E = {e1=(1,2), e2=(2,3), e3=(1,3)}.

Be1 (1→2)e2 (2→3)e3 (1→3)
1−10−1

Conferência de BBT: a diagonal é (2, 2, 2) — cada vértice incide em dois arcos. Fora da diagonal, todos os pares estão ligados por um arco, e as entradas valem −1. O grafo subjacente é K3, cujo laplaciano é exatamente 2I − (J−I) = 3I − J ✔

Grafo subjacente

O grafo subjacente de D é o grafo não-dirigido obtido ao esquecer a orientação: {u,v} é aresta se pelo menos um entre (u,v) e (v,u) existe. Se os dois sentidos existem, o subjacente tem uma aresta (grafo simples), não duas. O exercício 51 pede essa conversão em O(|V| + |E|) a partir das listas de D.

Definição · sorvedouro

Um sorvedouro em um grafo dirigido de ordem n é um vértice com grau de entrada n−1 e grau de saída 0: todo mundo aponta para ele, e ele não aponta para ninguém. Há no máximo um — se existissem dois, cada um precisaria de um arco até o outro, contradizendo grau de saída 0.

Com matriz de adjacências, a definição pede para olhar uma linha e uma coluna inteiras, o que parece Θ(n2) se for feito para cada vértice. O exercício 52 pede O(n). A ideia é de eliminação de candidatos: cada consulta Aij descarta pelo menos um entre i e j (se a entrada é 1, i tem arco de saída; se é 0, j não tem arco de entrada vindo de i). Depois de n−1 consultas resta um candidato, verificado em mais O(n) leituras.

Receita: operações em dígrafos pela estrutura
  1. Aresta dada, extremos? Vetores S, C: O(1). Matriz B: varrer a coluna, O(|V|).
  2. Aresta e incide no vértice v? Ambos O(1): compare S[e] e C[e] com v, ou leia B(v,e).
  3. Tudo o que sai/chega de v? Ambos O(|E|), salvo se você já tiver listas de adjacência (entrada e saída), caso em que a resposta está pronta em O(d(v)).

6.9 Resumo do bloco

Resumo do bloco em oito linhas
  • Trabalhe sempre com V = {1,…,n}; o mapeamento é um isomorfismo.
  • Aij = 1 sse {i,j} é aresta; diagonal zero; A simétrica; espaço Θ(n2).
  • Lista: vetor de vizinhanças, espaço Θ(|V| + |E|), ordem dos vizinhos irrelevante.
  • Teste de aresta: matriz O(1), lista O(n). Devolver E: o contrário.
  • f = O(g) pede constantes c, n0. Polinomialidade não depende de matriz versus lista (obs. 7).
  • (A2)ii = d(i), (A2)ij = |N(i) ∩ N(j)|, tr(A3)∕6 é o número de triângulos.
  • Kn tem autovalores n−1 e −1; em grafo r-regular, r é autovalor. Autovalores distintos ⇒ Aut(G) abeliano.
  • Em dígrafo: S, C e B respondem incidência; BBT é o laplaciano do subjacente; sorvedouro se detecta em O(n) na matriz.

Exercícios 40 a 52

O que é cobrado: álgebra de O-grande, independência polinomial das representações, leitura combinatória de A2 e A3, incidência em dígrafos, autovalores, conversão ao subjacente e detecção de sorvedouro.

Ex. 40

Mostre que se f(n) = O(g(n)) então O(f(n)) + O(g(n)) = O(g(n)).

Resolução

Interpretamos O(h) como o conjunto das funções (nos naturais, positivas a partir de algum ponto) que são O(h), e a soma de conjuntos como {h1 + h2 : h1 ∈ O(f), h2 ∈ O(g)}.

Inclusão ⊆

Seja h = h1 + h2 com h1 = O(f) e h2 = O(g). Por hipótese f = O(g), e O é transitiva: h1 = O(f) = O(g). Explicitamente, existem constantes positivas tais que, para n grande,

h1(n) ≤ c1 f(n) ≤ c1cf g(n),    h2(n) ≤ c2 g(n).

Logo h(n) ≤ (c1cf + c2) g(n), e h = O(g).

Inclusão ⊇

A função nula está em O(f), portanto O(g) = {0} + O(g) ⊆ O(f) + O(g).

As duas inclusões dão a igualdade. A hipótese f = O(g) é essencial: sem ela, O(f) + O(g) = O(f+g), que pode ser estritamente maior que O(g) (tome f(n) = n2 e g(n) = n).

Ex. 41

É verdade que para todo G vale que |E(G)| = O(|V(G)|) para |V(G)| suficientemente grande?

Resolução

Não.

O-grande compara funções, não um grafo isolado (todo grafo finito satisfaz m ≤ cn para c grande o bastante, o que esvazia a pergunta). A leitura razoável — e a única que torna o enunciado não-trivial — é: existem constantes c e n0 tais que |E(G)| ≤ c |V(G)| para todo grafo G com |V(G)| ≥ n0.

Isso é falso. Para o grafo completo Kn,

|E(Kn)| = n(n−1)2,

e n(n−1)∕(2n) = (n−1)∕2 não é limitado. Qualquer candidato a constante c falha em todos os Kn com n > 2c+1.

A afirmação passaria a ser verdadeira se restringíssemos a família: grafos com grau máximo limitado, grafos planares, árvores, todos satisfazem m = O(n). O quantificador do enunciado é “para todo G”, e isso inclui os completos.

Ex. 42

É verdade que para todo G vale que log |E(G)| = O(log |V(G)|) para |V(G)| suficientemente grande?

Resolução

Sim, para grafos simples com pelo menos uma aresta. (Se |E| = 0, log |E| não está definido; o enunciado original não trata esse caso, e é assim que resolvemos.)

Em grafo simples, 1 ≤ |E(G)| ≤ n(n−1)∕2 ≤ n2, onde n = |V(G)|. O logaritmo (qualquer base > 1) é crescente, logo

0 ≤ log |E(G)| ≤ log(n2) = 2 log n = 2 log |V(G)|.

As constantes c = 2 e n0 = 2 funcionam para todo grafo simples com n ≥ 2 e m ≥ 1. A desigualdade é uniforme — o contrário do exercício 41.

A intuição: elevar n ao quadrado só dobra o logaritmo. Por isso famílias densas e famílias esparsas são indistinguíveis em escala log-log: ambas têm log m = Θ(log n) assim que m ≥ 2.

Ex. 43

Prove a afirmação feita na observação 7.

Dica

Mostre que o tamanho da matriz e o tamanho da lista são, cada um, limitados por um polinômio no outro. Use 0 ≤ m ≤ n(n−1)∕2 e n ≤ n+m.

Resolução

Sejam n = |V| e m = |E|. Escreva NA para o tamanho da representação por matriz e NL para o tamanho da representação por lista. A menos de constantes de implementação (tamanho da palavra, ponteiros),

NA = Θ(n2),    NL = Θ(n + m).

Em grafo simples, 0 ≤ m ≤ n(n−1)∕2. Daí as duas comparações:

  • NL = Θ(n+m) = O(n + n2) = O(n2) = O(NA). Mais precisamente, NL = O(NA).
  • Como n ≤ n+m, n = O(NL), logo NA = Θ(n2) = O(NL2).

De polinomial na matriz para polinomial na lista

Se o tempo satisfaz T ≤ p(NA) para um polinômio p de grau k, então T = O(NAk) = O(NL2k), que é polinomial em NL.

De polinomial na lista para polinomial na matriz

Se T ≤ q(NL) com q de grau k, então T = O(NLk) = O(NAk), polinomial em NA.

Portanto as duas noções de “algoritmo polinomial em grafos” coincidem. (O grau do polinômio pode mudar — típico, dobra — mas a classe é a mesma.) Isso é a observação 7.

O que a prova usa de grafo simples

A cota m = O(n2) falha em multigrafos com multiplicidade ilimitada. Aí lista e matriz (ainda n × n, agora com inteiros) deixam de ser polinomialmente relacionadas se a multiplicidade puder ser exponencial em n. O original trata grafos simples, e é esse o cenário da prova.

Ex. 44

Sejam G um grafo, A a sua matriz de adjacências e b(i,j) as entradas da matriz A2. Que parâmetro de G está associado ao número b(i,i), para cada i ∈ {1, 2, …, |V(G)|}? Qual a relação entre b(i,j) e NG(i), NG(j) quando i ≠ j?

Resolução

Por definição do produto, b(i,j) = ∑k=1..n Aik Akj. Como A é 0-1, o termo k vale 1 exatamente quando {i,k} e {k,j} são arestas — isto é, quando i — k — j é um passeio de comprimento 2.

Diagonal

Para i = j, o passeio é i — k — i, logo k percorre exatamente NG(i). Portanto

b(i,i) = dG(i).

O parâmetro associado é o grau de i.

Fora da diagonal

Para i ≠ j, o índice k precisa ser vizinho de ambos. Além disso k ≠ i e k ≠ j automaticamente (não há laços). Logo

b(i,j) = |NG(i) ∩ NG(j)|.

Conferência no grafo da Figura 1: b(1,1) = 2 = d(1), b(2,4) = 0 = |N(2) ∩ N(4)|, b(1,4) = 1 = |{2}| ✔

Ex. 45

Para um grafo dirigido dizemos que a aresta (u,v) ∈ E sai de u e chega em v. Os vetores de incidências de um grafo dirigido D = (V, E) são os vetores S e C indexados por E tais que, para e = (u,v) ∈ E, temos S[e] = u e C[e] = v. Determine o tempo para:

(i) dados e ∈ E e v ∈ V, determinar se e incide em v;

(ii) dado e ∈ E, determinar suas extremidades;

(iii) dado v ∈ V, determinar as arestas que saem de v e determinar as arestas que chegam em v.

Uma matriz de incidências de um grafo dirigido D = (V, E) é uma matriz B de dimensão |V| × |E| (as linhas são indexadas por V e as colunas por E) tal que

B(i,j) = −1 se a aresta j sai do vértice i; +1 se chega no vértice i; 0 caso contrário.

(a) Determine o tempo para:

(i) dados e ∈ E e v ∈ V, determinar se e incide em v;

(ii) dado e ∈ E, determinar suas extremidades;

(iii) dado v ∈ V, determinar as arestas que saem de v e determinar as arestas que chegam em v.

(b) Determine o que as entradas da matriz |V| × |V| dada por B · BT representam, onde BT é a matriz transposta de B.

Dica

Vetores dão acesso direto por aresta; a matriz B dá acesso direto à entrada (v,e), mas varrer uma coluna custa |V| e varrer uma linha custa |E|. Para (b), calcule (BBT)ik = ∑e B(i,e) B(k,e) separando os casos i = k e i ≠ k.

Resolução

Vetores S e C

(i) O(1). A aresta e incide em v se e somente se S[e] = v ou C[e] = v: duas comparações.

(ii) O(1). As extremidades são exatamente S[e] e C[e].

(iii) O(|E|). Não há índice por vértice: é preciso percorrer todas as arestas, e para cada e testar se S[e] = v (sai) ou C[e] = v (chega). Um único scan resolve as duas listas.

(a) Matriz B

(i) O(1). Basta ler B(v, e): a aresta incide no vértice se e somente se a entrada é não-nula.

(ii) O(|V|). A coluna de e tem |V| entradas e exatamente duas delas são não-nulas. Varrê-la devolve o −1 (saída) e o +1 (chegada).

(iii) O(|E|). A linha de v tem |E| entradas: cada −1 é um arco que sai, cada +1 é um arco que chega.

Comparando com os vetores: (i) empata; (ii) os vetores ganham (O(1) contra O(|V|)); (iii) empata em O(|E|). A matriz B não é a estrutura certa para “tudo o que toca v” — listas de adjacência (de saída e de entrada) resolvem isso em O(d(v)).

(b) O produto BBT

A entrada (i,k) vale ∑e ∈ E B(i,e) B(k,e).

Se i = k: para cada arco incidente a i, o produto é (±1)2 = 1. Os demais arcos contribuem 0. Logo

(BBT)ii = din(i) + dout(i),

o grau total de i no grafo subjacente (contando os dois sentidos, se ambos existirem, como duas incidências).

Se i ≠ k: o produto B(i,e) B(k,e) só é não-nulo quando e tem um extremo em i e o outro em k. Nesse caso vale (−1)·(+1) = −1, independentemente do sentido. Se há aik arcos de i para k e aki no sentido oposto,

(BBT)ik = −(aik + aki).

Em dígrafo simples sem 2-ciclo, isso é −1 se os dois vértices são adjacentes no subjacente e 0 caso contrário. Em outras palavras: BBT é o laplaciano do grafo subjacente (com multiplicidade, se ambos os sentidos existirem).

Conferência na Figura 3: diagonal (2,2,2), fora da diagonal todos −1, que é o laplaciano de K3 ✔

Ex. 46

Seja G um grafo qualquer e A sua matriz de adjacências. Como é possível determinar o número de triângulos de um grafo G qualquer a partir de A3?

Resolução

A entrada (A3)ii é o número de passeios fechados de comprimento 3 com início (e fim) em i.

Cada triângulo {i,j,k} produz, no vértice i, exatamente dois tais passeios: ijki e ikji. O mesmo vale em j e em k. Passeios fechados de comprimento 3 que não vêm de um triângulo não existem em grafo simples: a sequência iabi com a ≠ b força as três arestas {i,a}, {a,b}, {b,i}, isto é, um triângulo. (Voltar e ir, iaia, tem comprimento 3 mas termina em a ≠ i, e não entra na diagonal.)

Portanto cada triângulo é contado 3 · 2 = 6 vezes no traço, e

número de triângulos de G = tr(A3)6 = 16 ∑i ∈ V (A3)ii.

Conferência na Figura 1: diagonal de A3 igual a (2,2,2,0), traço 6, um triângulo ✔

Ex. 47

Em 1990, Coppersmith e Winograd mostraram um algoritmo que determina o produto de duas matrizes n × n usando O(n2,376) operações aritméticas. Como esse pode ser usado para determinar se um grafo tem triângulo?

Dica

Você não precisa de A3 inteira. Um triângulo é uma aresta cujos extremos têm um vizinho comum — e vizinho comum é entrada positiva de A2.

Resolução

Algoritmo. Com o produto rápido, calcule A2 em O(n2,376). Em seguida percorra os pares i < j e teste se

Aij = 1   e   (A2)ij ≥ 1.

Se algum par passa no teste, i e j são adjacentes e têm um vizinho comum: os três formam um triângulo. Se nenhum par passa, não há triângulo. A varredura custa O(n2), absorvido por O(n2,376).

Equivalentemente, calcule A3 = A(A2) com mais um produto e devolva “sim” se e somente se tr(A3) > 0 (exercício 46). Dois produtos continuam O(n2,376).

O expoente 2,376 é o número do artigo de 1990 citado no enunciado. Algoritmos posteriores baixaram o expoente do produto de matrizes; o método (reduzir triângulo a produto) permanece o mesmo.

Ex. 48

Sejam G um grafo e A sua matriz de adjacências. Prove que se os autovalores de A são distintos então o grupo dos automorfismos é abeliano.

Dica

Um automorfismo vira uma matriz de permutação P que comuta com A. Se A tem autovalores distintos, quem comuta com A é diagonal na mesma base de autovetores — e matrizes diagonais comutam entre si.

Resolução

Como A é real simétrica, existe matriz ortogonal Q tal que A = QDQT, com D = diag(λ1,…,λn) e λ1, …, λn reais e, por hipótese, dois a dois distintos.

Seja φ um automorfismo de G e P a matriz de permutação associada: Pi, φ(i) = 1. Preservar adjacência é equivalente a PT A P = A, ou ainda PA = AP: todo automorfismo comuta com A.

Afirmação. Se MA = AM, então QT M Q é diagonal.

De fato, escreva B = QT M Q. A comutação MA = AM traduz-se em BD = DB. Igualando a entrada (i,j),

Bij λj = λi Bij ⟹ Bij (λj − λi) = 0.

Se i ≠ j, o fator λj − λi é não-nulo, logo Bij = 0. Assim B é diagonal.

Em particular, as matrizes de permutação Pφ e Pψ de dois automorfismos são ambas diagonais na base das colunas de Q. Matrizes diagonais comutam, portanto Pφ Pψ = Pψ Pφ, isto é, φ ∘ ψ = ψ ∘ φ. O grupo Aut(G) é abeliano.

Onde a hipótese entra

Sem autovalores distintos, B só é bloco-diagonal por autoespaço, e dois automorfismos podem misturar um autoespaço de dimensão ≥ 2 de formas que não comutam. O contraexemplo clássico é K3: autovalores 2, −1, −1 (não distintos) e Aut(K3) ≃ S3, não abeliano.

Resolução

tr(A) = 0.

Pelo exercício 44, (A2)ii = d(i). O teorema do aperto de mão dá

tr(A2) = ∑i ∈ V d(i) = 2|E(G)|.

Ex. 50

Por A ser uma matriz simétrica, sabemos da Álgebra Linear que todos os seus autovalores são números reais. Determine os autovalores da matriz de adjacências do grafo completo Kn. Mostre que se G é r-regular então r é um autovalor de A.

Dica

A(Kn) = J − I. Os autovalores de J são n (vetor de uns) e 0 (o hiperplano ortogonal). Para a segunda parte, some cada linha de A.

Resolução

Autovalores de Kn

A matriz de adjacências de Kn é J − I, onde J é a matriz n × n de uns e I a identidade. Seja 1 o vetor de uns. Então J1 = n1, logo

(J − I)1 = (n − 1)1.

Se x é ortogonal a 1, temos Jx = 0, logo (J − I)x = −x. Esse autoespaço tem dimensão n−1. Portanto os autovalores são

n − 1  (multiplicidade 1)    e    −1  (multiplicidade n − 1).

Conferência com n = 1: K1 tem A = [0], autovalor 0 = 1−1, e o autoespaço de −1 tem dimensão 0 ✔ Com n = 2: A = (0 1; 1 0), autovalores 1 e −1 ✔

Grafo r-regular

Se todo vértice tem grau r, cada linha de A tem exatamente r uns. Logo

A1 = r1.

Assim r é autovalor, com autovetor 1. (Em particular, o caso Kn recupera r = n−1, já obtido.)

Ex. 51

Dada uma representação por listas de adjacências de um grafo dirigido D, descreva um algoritmo com tempo de execução O(|V(D)| + |E(D)|) para computar a representação por listas de adjacências do grafo subjacente.

Dica

Construa primeiro as listas reversas (quem aponta para quem) no mesmo tempo. Depois, para cada vértice, una saída e entrada eliminando duplicatas com um vetor booleano de marcas que você reinicia só nos vizinhos marcados — não zere o vetor inteiro a cada vértice, senão cai em O(n2).

Resolução

O grafo subjacente tem a mesma ordem, e {u,v} é aresta se pelo menos um entre (u,v) e (v,u) pertence a E(D). Listas de D: N[u] = vértices v com (u,v) arco.

Subjacente(D)
// N[u] = lista de saída de u em D; devolve N' do grafo subjacente
para cada u ∈ V(D) faça R[u] ← lista vazia
para cada u ∈ V(D) faça
    para cada v ∈ N[u] faça insere u em R[v]
// R[u] = lista de entrada de u
para cada u ∈ V(D) faça M[u] ← falso; N'[u] ← lista vazia
para cada u ∈ V(D) faça
    para cada v ∈ N[u] ∪ R[u] faça
        se v ≠ u e M[v] = falso então
            M[v] ← verdadeiro; insere v em N'[u]
    para cada v ∈ N'[u] faça M[v] ← falso
devolva N'

Correção. Depois do primeiro duplo laço, v ∈ R[u] se e somente se (v,u) é arco. No laço principal, v entra em N′[u] se aparece em pelo menos uma das duas listas e v ≠ u (laços, se o dígrafo os tiver, não geram aresta no subjacente simples). A marca M impede duplicata quando os dois sentidos existem. Reiniciar M só em N′[u] deixa o vetor pronto para o próximo vértice.

Término. Cada lista é finita; não há laço de espera.

Complexidade. Construir R percorre cada arco uma vez: O(|V| + |E|). No laço principal, cada arco é inspecionado no máximo quatro vezes (como saída de um extremo, entrada do outro, e as duas redefinições de marca). Reiniciar M custa o tamanho de N′[u], no máximo o grau no subjacente, cuja soma é O(|E|). Total O(|V| + |E|).

O erro clássico

Zerar M[1..n] a cada vértice custa O(n2) e estraga a cota. Outro erro: inserir v em N′[u] e u em N′[v] ao ver o arco (u,v), sem marcas — o 2-ciclo duplica a aresta nas duas listas.

Ex. 52

Quando uma representação por uma matriz de adjacências é utilizada, muitos algoritmos sobre grafos gastam tempo Θ(|V|2), mas existem algumas exceções. Mostre que determinar se um grafo orientado contém um sorvedouro — isto é, um vértice com grau de entrada |V|−1 e grau de saída 0 — pode ser determinado em tempo O(|V|) quando uma representação por matriz é utilizada.

Dica

Cada leitura Aij elimina pelo menos um candidato. Depois de n−1 leituras resta um só; verifique a linha e a coluna desse candidato.

Resolução

O enunciado fala em “grafo orientado”. Lemos no sentido usual de dígrafo (possivelmente sem 2-ciclos); a definição de sorvedouro que o próprio enunciado dá não usa essa restrição, e o algoritmo abaixo vale para qualquer dígrafo simples, com Aij = 1 sse existe o arco (i,j). Há no máximo um sorvedouro: dois vértices com saída 0 não podem apontar um para o outro, logo nenhum dos dois tem entrada n−1.

Tem-Sorvedouro(A, n)
// A é a matriz n × n do dígrafo; devolve o sorvedouro ou “não existe”
i ← 1
para j ← 2 até n faça
    se A[i, j] = 1 então i ← j
// i é o único candidato
para k ← 1 até n faça
    se k ≠ i e (A[i, k] = 1 ou A[k, i] = 0) então
        devolva “não existe”
devolva i

Invariante da eliminação. No teste A[i,j] temos sempre i ≠ j (o candidato só avança para o j corrente, e j cresce). Se a entrada é 1, o vértice i tem arco de saída, logo não é sorvedouro: descartamos i e passamos a j. Se a entrada é 0, o vértice j não recebe arco de i, logo não tem entrada n−1: descartamos j e mantemos i. Cada um dos n−1 testes elimina um vértice. O sobrevivente i é o único possível sorvedouro.

Se o sorvedouro s existe, ele sobrevive. Enquanto o candidato i é diferente de s, o teste contra j = s lê A[i,s] = 1 (todo mundo aponta para o sorvedouro) e o candidato vira s. Depois disso, para todo j ≠ s lê-se A[s,j] = 0, e o candidato permanece s.

Verificação. A segunda etapa confere grau de saída 0 (linha i nula fora da diagonal) e grau de entrada n−1 (coluna i toda 1 fora da diagonal). Se o candidato falhar, não há sorvedouro.

Complexidade. Primeira etapa: n−1 leituras da matriz. Segunda: no máximo 2(n−1) leituras. Total O(n) = O(|V|), sem varrer as n2 entradas.

Conferência numérica

Dígrafo em {1,2,3,4} com sorvedouro 4 e matriz

1234
10101
20011
31001
40000

Candidato inicial i = 1. j = 2: A[1,2] = 1 ⇒ i = 2. j = 3: A[2,3] = 1 ⇒ i = 3. j = 4: A[3,4] = 1 ⇒ i = 4. Linha 4 nula, coluna 4 igual a (1,1,1,0) ✔
