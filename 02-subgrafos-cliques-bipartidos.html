§2 Subgrafos

Objetivo do bloco: recortar pedaços de um grafo, distinguir os três tipos de recorte (qualquer, gerador e induzido) e contar recortes com uma propriedade dada.

2.1 A ideia e a definição

Quase toda pergunta interessante em teoria dos grafos é da forma “este grafo contém aquele padrão?”. Para formular isso precisamos de uma noção de “pedaço”. A ideia é a mais simples possível: um pedaço de G é um grafo cujos vértices e arestas já estavam em G.

Definição · subgrafo

O grafo H é um subgrafo do grafo G se, e somente se, V(H) ⊆ V(G) e E(H) ⊆ E(G). Nesse caso escrevemos H ⊆ G.

Atenção · são três condições, não duas

A definição começa com “o grafo H”. Então, antes de comparar conjuntos, é preciso que H seja um grafo: toda aresta de H tem de ser um par de vértices de H. Esquecer isso é o erro clássico do bloco.

Vamos usar como referência o mesmo grafo do Exemplo 1 do capítulo 1:

V(G) = {1, 2, 3, 4, 5, 6, 7, 8}
E(G) = { {1,2}, {1,5}, {2,5}, {3,4}, {6,7} }
Exemplo 3 · quatro candidatos, dois aprovados

São subgrafos de G:

G′ = ( {1,2,5}, { {1,5}, {5,2}, {1,2} } )   e   G″ = ( {3,5,6}, ∅ )

Não são subgrafos de G:

H = ( {1,2,3}, { {1,2}, {3,4} } ),   I = ( {1,2,3,4,9}, { {1,2}, {3,4} } ),   J = ( {1,2,3,4,8}, { {1,2}, {3,4}, {1,8} } )
CandidatoPor que falha
HNão é grafo. A aresta {3,4} usa o vértice 4, que não está em V(H) = {1,2,3}.
IÉ grafo, mas V(I) ⊄ V(G): o vértice 9 não existe em G.
JÉ grafo e V(J) ⊆ V(G), mas E(J) ⊄ E(G): {1,8} ∉ E(G).

Note que G″ = ({3,5,6}, ∅) é subgrafo: três vértices soltos, sem nenhuma aresta. Um subgrafo não precisa “herdar” aresta alguma.

2.2 Subgrafo gerador

Definição · subgrafo gerador

Um subgrafo H ⊆ G com V(H) = V(G) é um subgrafo gerador de G.

Isto é: um subgrafo gerador mantém todos os vértices e escolhe um subconjunto das arestas. É o tipo de recorte que aparece em árvores geradoras e em emparelhamentos perfeitos. Em G da Figura 1 existem 25 = 32 subgrafos geradores, um para cada subconjunto das 5 arestas.

2.3 Subgrafo induzido por um subconjunto de vértices

O recorte mais importante é o que não deixa escolha nenhuma: fixamos um conjunto de vértices e ficamos com todas as arestas de G que couberem dentro dele.

Definição · subgrafo induzido por U

Se U ⊆ V(G), o subgrafo induzido por U, denotado G[U], é

G[U] = ( U,  { {u,v} ∈ E(G) : u ∈ U e v ∈ U } ).
Intuição

Apague de G os vértices que estão fora de U e, com eles, toda aresta que os tocava. O que sobra é G[U]. Não há liberdade: dado U, o grafo G[U] é único. Por isso um grafo de ordem n tem exatamente 2n subgrafos induzidos por vértices (um por subconjunto de V), mas em geral muito mais subgrafos.

Na Figura 1: G[{1,2,5}] = G′ (o triângulo inteiro) e G[{3,5,6}] = G″ (três vértices sem arestas, porque nenhum dos pares {3,5}, {3,6}, {5,6} é aresta de G).

Exemplo 4 · induzido × não induzido

O original ilustra esta distinção com um diagrama que não pôde ser recuperado; o exemplo abaixo foi construído para esta versão e cumpre o mesmo papel. Tome

V(G) = {1,2,3,4,5},  E(G) = { {1,2}, {2,3}, {3,4}, {4,5}, {5,1}, {1,3} }.

Então H = G[{1,2,3}] é subgrafo induzido, enquanto I = ( {1,2,3}, { {1,2}, {2,3} } ) é subgrafo mas não é induzido: os vértices de I são os mesmos de H, mas I deixou de fora a aresta {1,3}, que G oferece.

2.4 Subgrafo induzido por um subconjunto de arestas

Também podemos fazer o recorte começando pelas arestas. Aí são os vértices que ficam determinados: entram exatamente os que aparecem em alguma aresta escolhida.

Definição · subgrafo induzido por M

Se M = {e1, e2, …, em} ⊆ E(G), o subgrafo induzido por M, denotado G[M], tem como conjunto de vértices e1 ∪ e2 ∪ ⋅⋅⋅ ∪ em e como conjunto de arestas o próprio M:

G[M] = ( ⋃i=1..m ei,  M ).

Cada aresta é um conjunto de dois vértices, então a união das arestas é literalmente o conjunto dos extremos usados. Consequência: G[M] nunca tem vértice isolado — todo vértice dele está em pelo menos uma aresta de M.

2.5 Receita: é subgrafo? é induzido?

Receita · como atacar esse tipo de exercício
  1. É grafo? Toda aresta de H é um par de elementos de V(H)? Se não, pare: não é nem grafo.
  2. Vértices. Confira V(H) ⊆ V(G).
  3. Arestas. Confira E(H) ⊆ E(G), aresta por aresta.
  4. É gerador? Só se V(H) = V(G).
  5. É induzido por vértices? Compare E(H) com E(G[V(H)]). Se faltar uma única aresta de G entre dois vértices de H, não é induzido.
  6. Para contar recortes: escolha quem determina o recorte. Subgrafos induzidos por vértices ↔ subconjuntos de V; subgrafos geradores ↔ subconjuntos de E; subgrafos induzidos por arestas ↔ subconjuntos não vazios de E (e o vazio, se quiser incluir o grafo vazio).
Atenção · “induzido” é uma restrição, não um bônus

Exigir que o subgrafo seja induzido diminui o que você pode encontrar. Muitas vezes o maior subgrafo com uma propriedade é bem maior que o maior subgrafo induzido com a mesma propriedade — é exatamente o que acontece no exercício 18.

Resumo do bloco em cinco linhas
  • H ⊆ G: H é grafo, V(H) ⊆ V(G) e E(H) ⊆ E(G).
  • Gerador: mesmos vértices, arestas à escolha.
  • Induzido por U: vértices à escolha, arestas obrigatórias — todas as de G dentro de U.
  • Induzido por M: arestas à escolha, vértices obrigatórios — os extremos de M, sem isolados.
  • Ordem n ⟹ exatamente 2n subgrafos induzidos por vértices.

Exercícios 17 e 18

O que é cobrado: contar subgrafos com uma propriedade e procurar um subgrafo induzido regular de tamanho máximo.

Ex. 17

Quantos subgrafos completos tem o grafo completo de ordem n?

Dica

Um subgrafo completo não tem liberdade nenhuma na escolha das arestas: escolhido o conjunto de vértices, o conjunto de arestas está determinado. Então a pergunta é sobre quantos conjuntos de vértices existem.

Resolução

Resposta: 2n.

Passo 1 — traduzir “subgrafo completo”. Seja Kn = (V, (V2)) com |V| = n. Um subgrafo completo é um H ⊆ Kn tal que H é completo, isto é,

E(H) = (V(H)2).

Passo 2 — a bijeção. Defina a aplicação que leva U ⊆ V no grafo HU = (U, (U2)). Ela está bem definida e é uma bijeção entre os subconjuntos de V e os subgrafos completos de Kn:

  • Cada HU é subgrafo completo. É completo por construção, e é subgrafo porque U ⊆ V e todo par de elementos de U também é par de elementos de V, logo (U2) ⊆ (V2). (Em Kn nenhuma aresta “falta”, e é isso que faz a inclusão ser automática.)
  • É injetora. U ≠ U′ ⟹ HU ≠ HU′, pois os conjuntos de vértices já diferem.
  • É sobrejetora. Se H é subgrafo completo, tome U = V(H); a condição do Passo 1 diz exatamente que H = HU.

Passo 3 — contar. O número de subconjuntos de um conjunto de n elementos é 2n. Separando por ordem k do subgrafo, obtemos a mesma conta pelo binômio de Newton:

∑k=0..n (nk) = 2n

Conferência com n = 3. Os subgrafos completos de K3 sobre {1,2,3} são: (∅,∅); três de ordem 1; três de ordem 2 (cada aresta com seus extremos); e o próprio K3. Total 1 + 3 + 3 + 1 = 8 = 23 ✔

Convenção usada

Contamos o grafo vazio (∅, ∅) como completo: a condição E = (V2) vale trivialmente quando V = ∅. Se o enunciado exigir pelo menos um vértice, a resposta é 2n − 1; se exigir pelo menos uma aresta, 2n − n − 1.

Observação que será útil no §3. Todo subgrafo completo de Kn é induzido, porque em Kn todas as arestas possíveis existem. Dito de outro modo: os subgrafos completos de um grafo G correspondem aos cliques de G — e em Kn todo conjunto de vértices é clique.

Ex. 18

Descubra um subgrafo induzido de

V(G) = {1,2,3,4,5,6,7,8}
E(G) = { {1,2}, {1,3}, {2,3}, {2,5}, {3,6}, {8,5}, {8,6}, {5,6}, {3,4}, {5,7} }

que seja 1-regular e com o maior número possível de arestas. (Qual a relação com a resolução do exercício 2 do capítulo 1?)

Dica

Se u ∈ U e G[U] é 1-regular, então U contém exatamente um vizinho de u — ou seja, U deixou de fora d(u) − 1 vizinhos. Olhe os vértices de grau alto (3 e 5, ambos de grau 4) e conte quantas exclusões eles custam.

Resolução

Passo 0 — o que se pede. Queremos U ⊆ V(G) tal que G[U] seja 1-regular, maximizando o número de arestas. Num grafo 1-regular cada vértice tem exatamente um vizinho, logo as arestas formam um pareamento perfeito de U e

|E(G[U])| = |U|2.

Maximizar arestas é, então, maximizar |U| (que precisa ser par).

Passo 1 — graus de G.

v12345678
d(v)23414312

Soma = 2+3+4+1+4+3+1+2 = 20 = 2 · 10 ✔ (conferência pelo teorema do aperto de mão, com |E(G)| = 10).

Passo 2 — |U| = 8 e |U| = 6 são impossíveis. Chame de exclusão cada vértice fora de U. Se u ∈ U, o grau de u em G[U] é o número de vizinhos de u que ficaram em U; para valer 1, é preciso excluir d(u) − 1 vizinhos de u.

  • |U| = 8: U = V(G) e G[U] = G, que não é 1-regular (o vértice 3 tem grau 4).
  • |U| = 6: há exatamente 2 exclusões. Se 3 ∈ U, seria preciso excluir 3 dos seus 4 vizinhos {1,2,4,6} — não cabe em 2 exclusões. Logo 3 ∉ U, e resta 1 exclusão. Se 5 ∈ U, seria preciso excluir 3 dos seus 4 vizinhos {2,6,7,8} — também não cabe. Logo 5 ∉ U, e as duas exclusões são exatamente 3 e 5, ou seja U = {1,2,4,6,7,8}. Mas o único vizinho de 4 é 3, que foi excluído: em G[U] o vértice 4 tem grau 0. Contradição.

Portanto |U| ≤ 4 e o número de arestas é no máximo 2.

Passo 3 — atingir o máximo. Tome U = {3,4,5,7}. Os pares dentro de U são {3,4} ✓ aresta, {5,7} ✓ aresta, e {3,5}, {3,7}, {4,5}, {4,7}, nenhum deles aresta de G. Assim

G[{3,4,5,7}] = ( {3,4,5,7}, { {3,4}, {5,7} } ),

que é 1-regular com 2 arestas — o máximo. Outras soluções: U = {3,4,5,8} e U = {1,2,6,8} (confira nos dois casos que os quatro pares “cruzados” não são arestas).

Relação com o exercício 2 do capítulo 1

O conjunto de arestas de um subgrafo 1-regular é precisamente um emparelhamento: arestas duas a duas sem extremo em comum. No exercício 2 procurávamos um emparelhamento que cobrisse as 4 amigas, isto é, um subgrafo 1-regular gerador daquele grafo bipartido. É o mesmo objeto, com uma exigência diferente:

§3 Clique, conjunto independente, grafo bipartido e corte

Objetivo do bloco: usar subgrafos induzidos para definir os parâmetros α, ω e χ, reconhecer grafos bipartidos e k-partidos, e decompor E(G) por um corte.

Os dois recortes mais extremos que se pode pedir a um subgrafo induzido são os dois casos degenerados: todas as arestas possíveis presentes, ou nenhuma. Cada um recebe um nome, e cada um gera um parâmetro numérico do grafo.

3.1 Clique, triângulo e o parâmetro ω(G)

Definição · clique

Se U ⊆ V(G) induz um grafo completo em G — isto é, se G[U] é completo — chamamos U de clique em G. Se além disso |U| = k, dizemos que U é um k-clique. Um 3-clique é um triângulo de G.

O tamanho do maior clique é denotado ω(G):

ω(G) = max { |A| : A ⊆ V(G) é um clique }

Em termos práticos: U é clique quando seus vértices são dois a dois adjacentes. Verificar um clique é conferir (|U|2) pares, um por um.

3.2 Conjunto independente e o parâmetro α(G)

Definição · conjunto independente

Todo U ⊆ V(G) tal que G[U] = (U, ∅) é chamado de conjunto independente de G, ou k-conjunto-independente quando |U| = k. O tamanho do maior conjunto independente é

α(G) = max { |A| : A ⊆ V(G) é um conjunto independente }

Ou seja: U é independente quando seus vértices são dois a dois não adjacentes. Note que a definição exige G[U] sem arestas, e não apenas “U sem arestas escolhidas” — aqui o fato de o subgrafo ser induzido é essencial.

Exemplo 5 · no grafo de referência da Figura 1

O subgrafo G′ = G[{1,2,5}] do Exemplo 3 é um 3-clique (um triângulo), e G″ = G[{3,5,6}] é um 3-conjunto-independente. Ainda na Figura 1:

  • Independentes: {3,5,6} e {1,4,6,8}. O segundo tem cardinalidade máxima: qualquer conjunto de 5 vértices contém dois do triângulo {1,2,5}, ou 3 e 4 juntos, ou 6 e 7 juntos. Logo α(G) = 4.
  • Cliques: {8}, {6,7} e {1,2,5}, o último de cardinalidade máxima. Logo ω(G) = 3.

Observação 2 · leia este aviso antes de tentar “calcular” α e ω

O tamanho do maior clique e o do maior conjunto independente são difíceis de calcular computacionalmente: os dois problemas pertencem à classe dos NP-difíceis. Uma consequência é que não se sabe se existem algoritmos cujo tempo de execução no pior caso seja um polinômio em |V(G)| + |E(G)| para resolvê-los. Achar um algoritmo polinomial, ou provar que ele não existe, é o problema P × NP — um dos sete problemas do milênio (dos quais restam seis em aberto), cada um com recompensa de US$ 1.000.000,00.

Na prática do curso isso significa: para calcular α ou ω de um grafo dado, você exibe um conjunto (limite inferior) e prova que nada maior funciona (limite superior). Não há fórmula.

3.3 A dualidade pelo complemento

Intuição · clique e independente são a mesma coisa vista do outro lado

“Dois a dois adjacentes” em G é exatamente “dois a dois não adjacentes” em G. Logo clique em G = conjunto independente em G, e daí ω(G) = α(G) e α(G) = ω(G). É o conteúdo do exercício 21, e é o truque que permite transportar qualquer teorema sobre cliques para um teorema sobre conjuntos independentes.

Conferência na Figura 1: ω(G) = 3, e de fato o maior conjunto independente de G tem 3 vértices — são justamente os vértices de {1,2,5}, que no complemento perderam todas as arestas entre si.

3.4 χ(G), relido como partição em conjuntos independentes

No capítulo 1 (exercícios 1 e 7) χ(G) apareceu como “o menor número de caixas”, ou seja, o menor número de cores em uma pintura dos vértices em que vértices adjacentes recebem cores diferentes. Traduzindo para a linguagem deste capítulo: cada classe de cor é um conjunto de vértices dois a dois não adjacentes, isto é, um conjunto independente.

Definição equivalente · número cromático
χ(G) = min { k : V(G) = V1 ∪ ⋅⋅⋅ ∪ Vk, com os Vi disjuntos e cada Vi independente }

É a demonstração pedida no exercício 22. Com essa leitura, três fatos ficam imediatos: χ(Kn) = n (nenhum par pode partilhar classe), χ(G) = 1 se e só se G não tem arestas e V(G) ≠ ∅, e χ(G) = 0 só para o grafo vazio.

Receita · as duas cotas para χ (exercício 23)
  1. Pelo clique: χ(G) ≥ ω(G) — um clique gasta uma cor por vértice.
  2. Pela contagem: χ(G) ≥ |V(G)| ∕ α(G) — cada classe cabe em no máximo α(G) vértices, então são necessárias pelo menos n∕α classes.
  3. Limite superior: exiba uma partição concreta. Se o valor coincide com uma das cotas, você achou χ exatamente.

Na Figura 1: ω = 3 e n∕α = 8∕4 = 2, então a primeira cota é melhor e dá χ ≥ 3; a partição {1,3,6,8} ∪ {2,4,7} ∪ {5} usa 3 classes independentes, logo χ(G) = 3 ✔

3.5 Grafos bipartidos e Kn,m

Definição · grafo bipartido

Um grafo G é bipartido se existem dois conjuntos independentes A e B em G que particionam V(G), isto é, com A ∩ B = ∅ e A ∪ B = V(G). Os conjuntos A e B são as partes de G.

Dito em uma frase: toda aresta tem uma ponta em cada parte, e nenhuma aresta fica dentro de uma parte. Por exemplo, o grafo

V(G) = {1,2,3,4,5,6,7,8}
E(G) = { {1,6}, {6,2}, {3,7}, {3,8}, {7,4}, {7,5} }

é bipartido, pois V(G) = {1,2,3,4,5} ∪ {6,7,8} e tanto {1,2,3,4,5} quanto {6,7,8} são independentes.

Definição · bipartido completo Kn,m

Um grafo bipartido G com partes A e B é completo se tem |A| ⋅ |B| arestas, ou seja

E(G) = { {a, b} ⊆ V(G) : a ∈ A e b ∈ B }.

Um grafo bipartido completo com partes de cardinalidade n e m é denotado Kn,m.

Observação 3 · convenção sobre os casos degenerados

Convencionamos que os grafos trivial (um único vértice) e vazio ((∅,∅)) são bipartidos. Isso é consistente com a definição: nada exige que as partes sejam não vazias, então basta tomar A = V(G) e B = ∅ — dois conjuntos independentes disjuntos cuja união é V(G). Mais geralmente, todo grafo sem arestas é bipartido. Guarde essa convenção: ela é o que faz o exercício 26 funcionar nos casos χ(G) ≤ 1.

Três maneiras de dizer a mesma coisa

G é bipartido ⟺ V(G) se parte em 2 conjuntos independentes ⟺ χ(G) ≤ 2. A última equivalência é o exercício 26 e é a forma mais útil na prática: para mostrar que um grafo não é bipartido, exiba um triângulo (ou, mais geralmente, um ciclo de comprimento ímpar). O grafo da Figura 1, por exemplo, não é bipartido, porque ω = 3 obriga χ ≥ 3.

3.6 Grafos k-partidos e a intuição do balanceamento

Definição · k-partido e k-partido completo

Um grafo G é k-partido, k ∈ ℕ, se existem k conjuntos independentes A1, …, Ak que particionam V(G): a união é V(G), cada Ai é independente e Ai ∩ Aj = ∅ para i ≠ j. É completo quando toda aresta possível entre partes distintas está presente.

Bipartido é o caso k = 2; e G é k-partido para algum k se e somente se χ(G) ≤ k. Num k-partido completo com partes de tamanhos a1, …, ak (somando n), as arestas são exatamente os pares que não estão dentro de uma mesma parte:

|E| = (n2) − ∑i=1..k (ai2)  =  12 ( n2 − ∑i=1..k ai2 )
(★)

A segunda forma sai da primeira usando (a2) = a2 − a2 e ∑ai = n. A fórmula (★) é a chave dos exercícios 29 e 30: com n e k fixos, maximizar arestas é minimizar ∑ai2.

Intuição do balanceamento

Uma soma de quadrados com soma fixa é mínima quando as parcelas são iguais: concentrar vértices numa parte grande desperdiça muitas arestas, porque os pares dentro de uma parte são justamente os proibidos. Uma parte com a vértices proíbe (a2) pares, e esse número cresce como a2. Portanto o melhor é deixar as partes o mais equilibradas possível — no máximo um vértice de diferença entre duas partes quaisquer.

3.7 E(A,B), corte e a decomposição de E(G)

Definição · arestas entre dois conjuntos

Sejam G um grafo e A, B ⊆ V(G) dois subconjuntos disjuntos. Definimos

E(A, B) = { {u, v} ∈ E(G) : u ∈ A e v ∈ B }
(11)

e o subgrafo bipartido induzido por A e B é o grafo bipartido ( A ∪ B,  E(A, B) ).

Definição · corte

Para A ⊆ V(G), escreva A = V(G) \ A. O conjunto de arestas E(A, A) é chamado de corte definido por A. Com ele podemos escrever

E(G) = E(G[A]) ∪ E(G[A]) ∪ E(A, A)
(12)

A leitura de (12) é a de uma classificação: escolhido A, cada aresta de G está em exatamente uma de três situações — dentro de A, dentro de A, ou atravessando de um lado para o outro. Como as três situações são mutuamente exclusivas, a união é disjunta e vale também a igualdade de contagem

|E(G)| = |E(G[A])| + |E(G[A])| + |E(A, A)|.
Atenção · três armadilhas do corte
  • E(A,B) só está definido para A e B disjuntos.
  • A notação é simétrica: E(A,B) = E(B,A), porque arestas são conjuntos e {u,v} = {v,u} (exercício 24).
  • |E(A, A)| conta arestas, não vértices. Um mesmo vértice de A pode receber várias arestas do corte — é o que derruba a igualdade proposta no exercício 28.

3.8 Resumo do bloco

O essencial em nove linhas
  • Clique: U com G[U] completo; ω(G) = maior clique. Triângulo = 3-clique.
  • Independente: U com G[U] = (U,∅); α(G) = maior independente.
  • Dualidade: ω(G) = α(G) e α(G) = ω(G).
  • Cromático: χ(G) = menor número de classes independentes que particionam V(G).
  • Cotas: χ(G) ≥ ω(G) e χ(G) ≥ |V(G)| ∕ α(G).
  • Bipartido ⟺ duas partes independentes ⟺ χ(G) ≤ 2. Trivial e vazio são bipartidos.
  • Kn,m: bipartido completo, n ⋅ m arestas.
  • k-partido completo: |E| = (n2 − ∑ai2)∕2; máximo com partes equilibradas.
  • Corte: E(G) é a união disjunta de E(G[A]), E(G[A]) e E(A, A).

Ex. 19

Mostre que em qualquer grafo G com pelo menos 6 vértices ou existe um 3-clique ou existe um 3-conjunto-independente. (Dica do original: exercício 6 do capítulo 1 e princípio da casa dos pombos sobre EK6(v).)

Dica

Fixe 6 vértices e um deles, v. As 5 arestas de K6 que saem de v se dividem em “arestas de G” e “arestas de G” (exercício 6: G ∪ G = K6). Pela casa dos pombos, um dos dois grupos tem pelo menos 3 arestas. Trabalhe com esses 3 vizinhos (ou 3 não vizinhos) de v.

Resolução

Passo 0 — reduzir a 6 vértices. Se |V(G)| ≥ 6, escolha W ⊆ V(G) com |W| = 6 e trabalhe em G[W]. Um clique ou um independente de G[W] também é clique ou independente de G, porque G[W] é induzido: as adjacências entre vértices de W são as mesmas nos dois grafos. Podemos, portanto, supor |V(G)| = 6.

Passo 1 — casa dos pombos em um vértice. Fixe v ∈ V(G) e considere os outros 5 vértices. Pelo exercício 6 do capítulo 1, G ∪ G = K6, e E(G) e E(G) são disjuntos. Assim as 5 arestas de EK6(v) ficam repartidas em duas “gavetas”: as que são arestas de G e as que são arestas de G. Como 5 > 2 · 2, alguma gaveta recebe pelo menos ⌈5∕2⌉ = 3 arestas.

Passo 2 — caso A: v tem 3 vizinhos. Sejam a, b, c ∈ NG(v) distintos.

  • Se algum dos pares {a,b}, {b,c}, {a,c} é aresta de G — digamos {a,b} — então {v,a,b} é um 3-clique, pois {v,a}, {v,b} e {a,b} são todas arestas.
  • Se nenhum dos três pares é aresta, então {a,b,c} é um 3-conjunto-independente.

Passo 3 — caso B: v tem 3 não vizinhos. Sejam a, b, c distintos, nenhum adjacente a v em G. O argumento é o espelho do anterior:

  • Se algum par entre a, b, c não é aresta — digamos {a,b} ∉ E(G) — então {v,a,b} é um 3-conjunto-independente.
  • Se os três pares são arestas, {a,b,c} é um 3-clique.

Em todos os casos obtivemos um 3-clique ou um 3-conjunto-independente. □

O número 6 é o melhor possível. Com 5 vértices a conclusão falha: no ciclo C5 (Figura 12), dois vértices adjacentes quaisquer têm o terceiro vizinho comum ausente, de modo que ω = 2, e qualquer 3 vértices incluem um par adjacente, de modo que α = 2.

Na linguagem da teoria de Ramsey, o que acabamos de provar é R(3,3) ≤ 6, e o C5 mostra que R(3,3) = 6.

Ex. 20

Dado um grafo G, denotamos por α(G) a cardinalidade do maior conjunto independente em G,

α(G) = max { |A| : A ⊆ V(G) é um conjunto independente }.

Prove que se d(G) > α(G) então G contém triângulo, para todo G. (Aqui d(G) é o grau médio, definido em (6) no capítulo 1.)

Dica

Prove a contrapositiva. Num grafo sem triângulo, o que se pode dizer do conjunto N(v) de vizinhos de um vértice qualquer?

Resolução

Provamos a contrapositiva: se G não contém triângulo, então d(G) ≤ α(G).

Passo 1 — sem triângulo, vizinhança é independente. Seja v ∈ V(G). Suponha que dois vizinhos distintos x, y ∈ N(v) fossem adjacentes. Então {v,x}, {v,y} e {x,y} seriam arestas e {v,x,y} um triângulo — contra a hipótese. Logo

N(v) é um conjunto independente, para todo v ∈ V(G).

Passo 2 — daí sai a cota. Pela definição de α como máximo sobre os independentes, e como |N(v)| = d(v),

d(v) = |N(v)| ≤ α(G)   para todo v ∈ V(G),

ou seja Δ(G) ≤ α(G). Pelo exercício 9 do capítulo 1, o grau médio fica entre o mínimo e o máximo, portanto

d(G) ≤ Δ(G) ≤ α(G).

Conclusão. Provamos “sem triângulo ⟹ d(G) ≤ α(G)”. A contrapositiva é exatamente o enunciado: se d(G) > α(G), então G contém triângulo. □

Duas observações
  • O argumento prova a versão mais forte Δ(G) > α(G) ⟹ G contém triângulo, já que d ≤ Δ. A versão com grau médio é a que costuma ser útil, porque o grau médio se calcula direto de |V| e |E|: d(G) = 2|E|∕|V|.
  • A recíproca é falsa: o triângulo K3 tem d = 2 e α = 1 (ok, 2 > 1), mas o grafo formado por um triângulo mais 10 vértices isolados contém triângulo e tem d = 6∕13 < 1 ≤ α = 11. Ter triângulo não obriga grau médio alto.
Ex. 21

Para todo grafo G, denotamos por ω(G) a cardinalidade do maior clique em G,

ω(G) = max { |A| : A ⊆ V(G) é um clique }.

Prove que ω(G) = α(G).

Dica

Não compare os números diretamente. Prove primeiro a afirmação sobre conjuntos: U é clique em G se e somente se U é independente em G. Dois máximos sobre a mesma família de conjuntos são iguais.

Resolução

(Nota: na extração do original a barra de complemento sobre o segundo G se perdeu, resultando em “ω(G) = α(G)”, que é falso — no triângulo ω = 3 e α = 1. O enunciado correto é o acima, com o complemento.)

Passo 1 — a afirmação de conjuntos. Seja U ⊆ V(G) = V(G). Afirmo:

U é clique em G  ⟺  U é conjunto independente em G.

De fato, para u ≠ v em U, a definição de complemento dá

{u,v} ∈ E(G)  ⟺  {u,v} ∉ E(G).

Então:

  • U clique em G significa G[U] completo, isto é, todo par de U está em E(G);
  • pela equivalência acima, isso é o mesmo que nenhum par de U estar em E(G), isto é, G[U] = (U, ∅), que é a definição de U independente em G.

Passo 2 — passar aos máximos. O Passo 1 diz que as duas famílias de conjuntos coincidem:

{ U ⊆ V : U é clique em G } = { U ⊆ V : U é independente em G }.

Máximos de |U| sobre famílias iguais são iguais, logo ω(G) = α(G). □

Corolário. Aplicando o resultado a G e usando G = G, obtemos também α(G) = ω(G).

Conferência. Na Figura 1, ω(G) = 3 (o triângulo {1,2,5}) e, no complemento, esses mesmos três vértices perdem todas as arestas entre si — e nenhum conjunto de 4 vértices de G é independente, porque seria um 4-clique em G. Logo α(G) = 3 ✔

Ex. 22

Redefina, para todo grafo G, o parâmetro χ(G) dado no exercício 7 do capítulo 1 em função dos conjuntos independentes de G. Esse parâmetro é conhecido na literatura como número cromático do grafo.

Resolução

A definição pedida.

χ(G) = min { k ∈ ℕ : existem V1, …, Vk independentes, disjuntos, com V1 ∪ ⋅⋅⋅ ∪ Vk = V(G) }

Equivalentemente: χ(G) é o menor k tal que G é k-partido.

Por que é a mesma coisa que no exercício 7. Lá χ(G) era o menor número de “caixas” (cores) numa distribuição em que dois vértices adjacentes nunca compartilham caixa. A tradução é uma bijeção entre os dois objetos:

função c : V(G) → {1,…,k}classes Vi = { v : c(v) = i }
cada vértice recebe exatamente uma coras classes são disjuntas e cobrem V(G)
c é própria: {u,v} ∈ E(G) ⟹ c(u) ≠ c(v)nenhuma classe contém os dois extremos de uma aresta, isto é, cada Vi é independente

A terceira linha é o ponto: “nenhuma aresta dentro de Vi” é exatamente G[Vi] = (Vi, ∅), a definição de conjunto independente. Como a correspondência preserva o número k, os dois mínimos coincidem.

Testes.

  • χ(Kn) = n: todo conjunto independente de Kn tem no máximo 1 vértice, então são necessárias n classes.
  • χ(G) = 1 ⟺ V(G) ≠ ∅ e E(G) = ∅, pois a única classe teria de ser V(G) independente.
  • χ(G) = 0 só para G = (∅,∅) (a união vazia de classes é ∅).
  • Na Figura 1: {1,3,6,8} ∪ {2,4,7} ∪ {5} são três classes independentes, e o triângulo impede duas; logo χ = 3.
Ex. 23

Use a definição do exercício 22: uma coloração ótima é uma partição de V(G) em χ(G) conjuntos independentes. Para a primeira desigualdade, pergunte quantos vértices de um clique podem cair na mesma classe. Para a segunda, some os tamanhos das classes.

Escreva n = |V(G)| ≥ 1, k = χ(G) e fixe uma partição ótima

Ex. 24

Prove que E(A, B) = E(B, A), segundo a definição dada em (11).

Resolução

Por (11), com A e B disjuntos,

E(A,B) = { {u,v} ∈ E(G) : u ∈ A e v ∈ B },    E(B,A) = { {u,v} ∈ E(G) : u ∈ B e v ∈ A }.

Provamos as duas inclusões. O único fato usado é que aresta é conjunto, e conjunto não tem ordem: {u,v} = {v,u}.

(⊆) Seja e ∈ E(A,B). Então e ∈ E(G) e podemos escrever e = {u,v} com u ∈ A e v ∈ B. Escreva agora a mesma aresta como e = {v,u} = {u′,v′} com u′ = v ∈ B e v′ = u ∈ A. Isso é precisamente a condição de pertencer a E(B,A). Logo e ∈ E(B,A).

(⊇) Idêntico, trocando os papéis de A e B.

Das duas inclusões, E(A,B) = E(B,A). □

Por que isso não é uma bobagem

A definição (11) parece assimétrica, porque nomeia um extremo de “u” e o outro de “v”. A demonstração mostra que a assimetria é só da escrita. Se as arestas fossem pares ordenados — como num grafo dirigido — a igualdade seria falsa, e aí E(A,B) e E(B,A) contariam arcos em sentidos opostos. É por isso que a hipótese “grafo simples não dirigido” aparece no argumento.

Ex. 25

Seja G = (A ∪ B, E) um grafo bipartido qualquer e suponha que |A| < |B|. É verdade que α(G) = |B|? Determine ω(G).

Resolução

Parte 1 · α(G) = |B|? Não necessariamente

O que sempre vale. A parte B é, por definição de grafo bipartido, um conjunto independente. Logo

α(G) ≥ |B|   (e também α(G) ≥ |A|, mas |B| é a melhor das duas).

Contraexemplo para a igualdade. Tome A = {a1, a2}, B = {b1, b2, b3} e E = { {a1, b1} }. Então |A| = 2 < 3 = |B|, mas

S = {a2, b1, b2, b3}

é independente: os bi não se ligam entre si (estão na mesma parte) e a2 não tem vizinho algum. Assim α(G) ≥ 4 > 3 = |B|. A resposta é, portanto, não.

Quando a igualdade vale. Se G = K|A|,|B| é bipartido completo, então nenhum conjunto independente contém vértices das duas partes (todo par cruzado é aresta); logo todo independente está inteiro em A ou inteiro em B, e

α(K|A|,|B|) = max{ |A|, |B| } = |B|.

De modo geral, quanto menos arestas o grafo tem, mais α(G) sobe acima de |B|. No extremo E = ∅ temos α(G) = |A| + |B|.

Parte 2 · o valor de ω(G)

Passo 1 — nenhum clique tem 3 vértices. Seja U um clique com |U| ≥ 3. Como U ⊆ A ∪ B, a casa dos pombos garante dois vértices distintos de U na mesma parte. Mas partes são independentes, então esses dois não são adjacentes — contradizendo U ser clique. Logo ω(G) ≤ 2.

Passo 2 — o valor exato. A hipótese |A| < |B| garante |B| ≥ 1, portanto V(G) ≠ ∅ e qualquer vértice isolado já é um 1-clique. Assim

ω(G) = 2, se E ≠ ∅;     ω(G) = 1, se E = ∅.

De fato, se existe uma aresta {a,b}, o conjunto {a,b} é um 2-clique. Resumindo: em grafo bipartido, o maior clique é uma aresta — e é esse o motivo pelo qual grafos bipartidos são “fáceis” para muitos problemas em que cliques atrapalham.

(Nota sobre o enunciado: ele não diz se A e B são uma bipartição fixada ou apenas alguma; adotamos a leitura natural de que A e B são as partes dadas. As respostas não mudam com a outra leitura, pois ω não depende da bipartição escolhida.)

Ex. 26

Prove que G é bipartido se e somente se χ(G) < 3.

Dica

χ(G) é inteiro, então χ(G) < 3 quer dizer χ(G) ∈ {0, 1, 2}. Use a definição do exercício 22 e não esqueça de tratar os casos χ = 0 e χ = 1 — é aí que entra a Observação 3.

Resolução

Como χ(G) ∈ ℕ, a condição χ(G) < 3 é o mesmo que χ(G) ≤ 2. Usamos a caracterização do exercício 22: χ(G) é o menor número de conjuntos independentes, disjuntos, cuja união é V(G).

(⟹) Bipartido implica χ(G) ≤ 2

Se G é bipartido, existem A e B independentes com A ∩ B = ∅ e A ∪ B = V(G). Essa é, literalmente, uma partição de V(G) em 2 conjuntos independentes. Como χ(G) é o mínimo sobre tais partições e exibimos uma com 2 classes, χ(G) ≤ 2.

(⟸) χ(G) ≤ 2 implica bipartido

Seja k = χ(G) ≤ 2 e tome uma partição ótima em k conjuntos independentes. Três casos:

  • k = 2: a partição é V(G) = V1 ∪ V2 com V1, V2 independentes e disjuntos. Tomando A = V1 e B = V2, a definição de bipartido está satisfeita.
  • k = 1: V(G) é ele mesmo independente, isto é, E(G) = ∅. Tome A = V(G) e B = ∅: são independentes (o vazio é independente), disjuntos e a união é V(G). Logo G é bipartido — em particular, todo grafo trivial é bipartido, conforme a Observação 3.
  • k = 0: a união de zero classes é ∅, então V(G) = ∅ e G é o grafo vazio, bipartido pela Observação 3 (tome A = B = ∅).

As duas implicações dão a equivalência. □

Onde a convenção é indispensável

Se exigíssemos partes não vazias na definição de bipartido, o grafo trivial e o vazio deixariam de ser bipartidos e a implicação (⟸) falharia justamente nos casos k ≤ 1. A Observação 3 existe para fechar esse buraco.

Uso prático. A equivalência transforma “é bipartido?” numa pergunta sobre coloração com 2 cores. Em particular, exibir um triângulo prova que o grafo não é bipartido: pelo exercício 23, χ(G) ≥ ω(G) ≥ 3.

Ex. 28

Dado um grafo G, defina para todo U ⊆ V(G) a vizinhança de U, denotada NG(U), por

NG(U) = ⋃u∈U NG(u).

É verdade que |E(U, U)| = |NG(U)|? Justifique.

Dica

Duas coisas dão errado, e vale a pena procurar as duas. Primeiro: NG(U) pode conter vértices de dentro de U. Segundo: um vértice fora de U pode ser vizinho de vários vértices de U. Teste com uma estrela.

Resolução

Resposta: não, a igualdade é falsa em geral — e falha nos dois sentidos.

Contraexemplo 1 · o corte é maior

Seja G = K1,3, a estrela com centro c e folhas x, y, z, e tome U = {x, y, z}. Então U = {c} e

NG(U) = N(x) ∪ N(y) ∪ N(z) = {c} ∪ {c} ∪ {c} = {c},   E(U, U) = { {x,c}, {y,c}, {z,c} }.

Logo |E(U, U)| = 3 ≠ 1 = |NG(U)|. A causa: a união de conjuntos não repete o centro, mas o corte tem uma aresta para cada vizinho em U.

Contraexemplo 2 · a vizinhança é maior

Seja G a única aresta {u,v} (mais nada) e U = {u, v}. Então U = ∅ e E(U, U) = ∅, mas

NG(U) = N(u) ∪ N(v) = {v} ∪ {u} = {u,v},

ou seja 0 ≠ 2. A causa: NG(U) pode conter vértices de U — a definição não os exclui.

O que é verdade

Contando o corte aresta por aresta a partir do lado de fora, cada w ∈ U contribui com |N(w) ∩ U| arestas, e só contribui se tiver algum vizinho em U, isto é, se w ∈ NG(U) \ U. Logo

|E(U, U)| = ∑w∈U |N(w) ∩ U|  ≥  | NG(U) \ U |,

com igualdade se e somente se todo vértice fora de U tem no máximo um vizinho em U (cada parcela não nula vale 1). Na estrela do contraexemplo 1 a parcela do centro vale 3, e é por isso que a igualdade falha.

Quando a igualdade do enunciado vale
  1. U é conjunto independente (garante NG(U) ∩ U = ∅, logo NG(U) \ U = NG(U)); e
  2. cada vértice de U tem no máximo um vizinho em U.

O caso mais simples em que as duas condições valem é U = {v} com um único vértice: aí |E(U, U)| = d(v) = |N(v)|, porque cada vizinho de v recebe exatamente uma aresta do corte. Um exemplo com |U| > 1: no grafo bipartido da Figura 5, tome U = {1,3}. Ele é independente, cada vértice de fora tem no máximo um vizinho em U, e de fato N(U) = {6,7,8} e o corte é { {1,6}, {3,7}, {3,8} } — três e três ✔

Ex. 29

Um grafo G é dito k-partido, para k ∈ ℕ, se existem k conjuntos independentes A1, A2, …, Ak que particionam V(G), ou seja, V(G) = A1 ∪ A2 ∪ ⋅⋅⋅ ∪ Ak, cada Ai é independente em G e Ai ∩ Aj = ∅ para i ≠ j. Prove que, dentre os grafos k-partidos completos (k ≥ 3) com n vértices, o número máximo de arestas é atingido quando | |Ai| − |Aj| | ≤ 1 para todos i, j ∈ {1, 2, …, k} distintos.

Dica

Escreva o número de arestas em função só dos tamanhos ai = |Ai| — é a fórmula (★) da seção 3.6. Depois suponha que alguma parte tenha pelo menos 2 vértices a mais que outra e mova um vértice da maior para a menor. O que acontece com ∑ai2?

Resolução

(O original escreve “i, j ∈ {1,2,…,n}”, claramente um lapso: os índices das partes vão de 1 a k. Corrigimos no enunciado acima.)

Passo 1 — reduzir a um problema numérico. Um grafo k-partido completo com n vértices fica inteiramente determinado (a menos de renomear vértices) pelos tamanhos das partes

a1, a2, …, ak ≥ 0,   a1 + a2 + ⋅⋅⋅ + ak = n.

Suas arestas são todos os pares de vértices exceto os que ficam dentro de uma mesma parte (esses são proibidos, pois cada parte é independente; e todos os outros estão presentes, pois o grafo é completo). Assim

|E| = (n2) − ∑i=1..k (ai2)  =  12 ( n2 − ∑i=1..k ai2 )
(★)

(A segunda igualdade usa (a2) = (a2 − a)∕2 e ∑ai = n, que cancela os termos lineares.) Como n está fixo, maximizar |E| é minimizar Q = ∑ai2.

Passo 2 — o máximo existe. Há um número finito de vetores (a1,…,ak) de inteiros não negativos somando n, e a família é não vazia. Então |E| atinge um máximo.

Passo 3 — o argumento de troca. Suponha que em uma configuração ótima existam índices i, j com

ai ≥ aj + 2.

Mova um vértice de Ai para Aj: os novos tamanhos são ai − 1 e aj + 1, e os demais não mudam (a soma continua n, e ainda temos k partes). A variação de Q é

ΔQ = (ai − 1)2 + (aj + 1)2 − ai2 − aj2 = 2(aj − ai) + 2 ≤ 2(−2) + 2 = −2 < 0.

Por (★), o número de arestas aumentou:

Δ|E| = − ΔQ2 = ai − aj − 1 ≥ 1.

Isso contradiz a otimalidade. Logo, em qualquer configuração ótima, ai ≤ aj + 1 para todos i, j, ou seja

| |Ai| − |Aj| | ≤ 1  para todos i ≠ j.
□

Passo 4 — e tal configuração existe (e é única). Escreva n = kq + r com 0 ≤ r < k. O vetor com r partes de tamanho q + 1 e k − r partes de tamanho q soma n e satisfaz a condição. Reciprocamente, se todos os tamanhos diferem por no máximo 1, eles assumem no máximo dois valores consecutivos q e q+1, e a soma n determina quantas partes têm cada valor: exatamente r com q+1. Portanto o ótimo é único a menos da ordem das partes — é o grafo do exercício 30.

Ex. 30

Mostre que, se n = kq + r com 0 ≤ r < k, então o número de arestas do grafo do exercício anterior é

12 (k − 1)k (n2 − r2) + (r2)

e que esse número é limitado por

≤ k − 1k · n22 .
Dica

O grafo ótimo tem r partes de tamanho q+1 e k − r de tamanho q. Calcule Q = ∑ai2, simplifique e depois elimine q usando kq = n − r. Para a cota, compare o resultado com (1 − 1∕k) n2∕2 e veja o que sobra.

Resolução

Passo 1 — os tamanhos. Pelo exercício 29, o grafo com o máximo de arestas tem partes equilibradas: com n = kq + r e 0 ≤ r < k, são r partes de tamanho q + 1 e k − r partes de tamanho q. Conferência da soma: r(q+1) + (k−r)q = kq + r = n ✔

Passo 2 — calcular Q = ∑ai2.

Q = r(q+1)2 + (k−r)q2 = r(q2 + 2q + 1) + kq2 − rq2 = kq2 + 2rq + r.

Passo 3 — eliminar q. De n = kq + r vem n2 = k2q2 + 2kqr + r2, ou seja

kq2 = n2 − 2kqr − r2k = n2 − r2k − 2qr.

Substituindo no Passo 2, os termos 2rq se cancelam:

Q = n2 − r2k − 2qr + 2rq + r = n2 − r2k + r.

Passo 4 — substituir em (★). Com |E| = (n2 − Q)∕2:

|E| = 12 ( n2 − n2 − r2k − r ) = 12 ( (n2 − r2) (1 − 1k) + r2 − r )

onde na segunda igualdade escrevemos n2 = (n2 − r2) + r2. Como 1 − 1∕k = (k−1)∕k e (r2 − r)∕2 = (r2), chegamos à fórmula pedida:

|E| = 12 (k − 1)k (n2 − r2) + (r2)
(30.1)

Passo 5 — a cota superior. Compare (30.1) com ((k−1)∕k) · n2∕2:

k−1k n22 − |E| = k−12k r2 − r2 − r2 = r2 ( r − rk − r + 1 ) = r(k − r)2k ≥ 0,

pois 0 ≤ r < k. Portanto

|E| = k−1k n22 − r(k−r)2k  ≤  k−1k n22,
□

com igualdade exatamente quando r = 0, isto é, quando k divide n e todas as partes têm o mesmo tamanho n∕k.

Sobre a leitura do enunciado original

A extração do original deixou o lado direito da cota ambíguo entre ((k−1)∕k) · (n2) e ((k−1)∕k) · n2∕2. A primeira leitura é falsa: com k = n = 3 o grafo ótimo é K3, com 3 arestas, enquanto (2∕3) · (32) = 2 < 3. Já a segunda dá (2∕3)(9∕2) = 3, com igualdade — é a cota clássica de Turán, e é ela que provamos acima.

Por que essa cota é famosa

O grafo k-partido completo equilibrado não tem nenhum Kk+1 (qualquer k+1 vértices têm dois na mesma parte, logo não adjacentes). O teorema de Turán diz que ele é o grafo com mais arestas entre todos os grafos de n vértices sem Kk+1 — e a cota (1 − 1∕k) n2∕2 é, portanto, o número máximo de arestas que se pode ter proibindo um clique de tamanho k+1. O caso k = 2 é o teorema de Mantel: um grafo sem triângulo tem no máximo n2∕4 arestas.
