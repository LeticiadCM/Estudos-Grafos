Exemplos

Abaixo estão alguns cenários em que grafos aparecem no dia a dia.

Rede de cidades

Os vértices são cidades e as arestas representam estradas ou rotas de transporte.

Rede social

Usuários são nós e conexões representam amizade, seguidores ou interações.

Mapa de dependências

Projetos e módulos podem ser representados como nós conectados por dependências.

Exemplo de código

grafo = {
  'A': ['B', 'C'],
  'B': ['A', 'D'],
  'C': ['A', 'D'],
  'D': ['B', 'C']
}

# DFS simples
visitados = set()

def dfs(no):
    if no in visitados:
        return
    visitados.add(no)
    print(no)
    for vizinho in grafo.get(no, []):
        dfs(vizinho)

dfs('A')
